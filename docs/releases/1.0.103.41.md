# PLANK 1.0.103.41 Windows Client

This Windows Client release repairs display-layout switching and shows the
active codec in the stream toolbar.

## Changes since 1.0.103.39

Revision 40 added the active-codec label and restarted a stream when the user
changed between single-display and two-display layouts. The replacement stream
could fail with HTTP 403 because it reused authorization state that the initial
session had already consumed.

Revision 41 retains the reconnect credentials and resume ticket needed by the
replacement session. It reauthenticates before requesting Host resume.

## Acceptance

A Windows Client `1.0.103.41` session connected to a Windows Host
`1.0.103.39` and switched from one remote display to two remote displays.
Both displays appeared, the toolbar reported the active codec, and the prior
HTTP 403 failure did not recur.

This acceptance result covers the one-to-two-display reauthentication fix. It
does not qualify Windows 10-bit 4:4:4, adaptive WAN behavior, every display
topology, or color matching across different physical monitor models and
connections.

## Remaining display work

- Offer a normal resizable window that can move between local displays.
- Define the Windows taskbar behavior for one logical session with two stream

- Reproduce any apparent inter-display color difference with matched displays

# PLANK 1.0.103.39 for Windows

This Windows release makes capture backend selection explicit and capability driven.

## Host

- Advertises only capture sources available on the running workstation.
- Uses DXGI Desktop Duplication first and Windows Graphics Capture as the fallback
  when `Automatic` is selected.
- Allows DXGI to be selected explicitly for the lowest-latency path.
- Allows Windows Graphics Capture to be selected explicitly for compatibility.
- Rejects Windows Graphics Capture for a spanned multi-monitor desktop instead of
  silently substituting another backend.

## Client

- Reads the host's advertised capture-source list.
- Shows only the capture choices supported by that host.
- Sends the exact DXGI or Windows Graphics Capture request selected by the user.
- Keeps compatibility with hosts that predate capture-source advertisement.

## Scope

This release does not add Windows 10-bit 4:4:4 capture. That work remains the next
Windows color-pipeline phase and must advertise only combinations that the capture,
encoder and client decoder can serve exactly.

Machine-specific deployment records remain outside the public source repositories.
